Nightline Roadster — Drift Lab

A browser-based 3D roadster drift prototype built with Three.js and procedural geometry.

Controls: W/Up accelerate, S/Down brake, A/D or arrows steer, Space handbrake, C cycle cameras, R reset. Touch controls appear on mobile.

Camera modes: chase, hood, cockpit, overhead and side.

Deploy by importing this repository into Vercel as a static site. No build command is required; output directory is the repository root.

This is an original prototype inspired by the reference videos, not an asset-identical replica of the original game.
